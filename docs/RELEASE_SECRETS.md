# Release Secrets Configuration

This document describes the secrets required for automated releases.

## Required Secrets

### GitHub Repository Secrets

Configure these in: **Settings → Secrets and variables → Actions**

| Secret | Required For | How to Get |
|--------|-------------|------------|
| `NPM_TOKEN` | npm publishing | [npm.js → Access Tokens](https://www.npmjs.com/settings/tokens) |
| `HOMEBREW_TAP_TOKEN` | Homebrew formula updates | [GitHub → Settings → Developer settings → Personal access tokens](https://github.com/settings/tokens) with `repo` scope |
| `CHOCOLATEY_API_KEY` | Chocolatey publishing | [Chocolatey → Account → API Keys](https://community.chocolatey.org/account) |
| `SNAPCRAFT_TOKEN` | Snap Store publishing | Run `snapcraft export-login --snaps repo-cli -` |

## Setup Instructions

### 1. NPM Token

```bash
# Login to npm
npm login

# Create automation token
npm token create --type=automation
```

Add the token as `NPM_TOKEN` in GitHub Secrets.

### 2. Homebrew Tap Token

1. Create a new repository: `your-username/homebrew-tap`
2. Create a Personal Access Token with `repo` scope
3. Add as `HOMEBREW_TAP_TOKEN` in GitHub Secrets

The Homebrew tap repository should have this structure:
```
homebrew-tap/
└── Formula/
    └── repo-cli.rb  (auto-generated by workflow)
```

### 3. Chocolatey API Key

1. Register at [chocolatey.org](https://community.chocolatey.org/)
2. Go to Account → API Keys
3. Create a new API key
4. Add as `CHOCOLATEY_API_KEY` in GitHub Secrets

### 4. Snapcraft Token

```bash
# Login to Snapcraft
snapcraft login

# Export credentials
snapcraft export-login --snaps repo-cli credentials.txt

# Copy content and add as SNAPCRAFT_TOKEN
cat credentials.txt
```

## Workflow Triggers

### Automatic (on tag push)

When a tag matching `@repo/cli@*` is pushed:

1. `binary-release.yml` builds binaries and creates GitHub Release
2. `publish-packages.yml` is triggered to publish to package managers

### Manual (workflow dispatch)

Run manually from Actions tab:

```
Actions → Publish to Package Managers → Run workflow
```

Enter the version number (e.g., `1.0.0`) to publish.

## Testing Releases

### Dry Run

```bash
# Test changeset version bump
pnpm changeset:version --dry-run

# Test npm publish
npm publish --dry-run
```

### Create Pre-release

Tag with pre-release version:
```bash
git tag @repo/cli@1.0.0-beta.1
git push origin @repo/cli@1.0.0-beta.1
```

Pre-releases:
- Create GitHub Release marked as pre-release
- Skip package manager publishing (Homebrew, Chocolatey, Snap)
- Still available via npm with `@beta` tag

## Troubleshooting

### Binary build fails

- Check Node.js version compatibility with pkg
- Verify ncc bundling works locally: `pnpm cli:bundle`

### npm publish fails

- Ensure `NPM_TOKEN` has automation permissions
- Check package version doesn't already exist

### Homebrew update fails

- Verify `HOMEBREW_TAP_TOKEN` has `repo` scope
- Ensure `homebrew-tap` repository exists

### Chocolatey push fails

- Verify package name isn't taken
- Check nuspec file is valid XML
- API key must have push permissions
